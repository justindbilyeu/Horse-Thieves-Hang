# Chapters

This is where scenes get assembled into structured narrative.

## Current Status

Still in inventory phase. Chapter structure will emerge after we have enough raw material.

## Possible Structures to Consider

- **Thematic** - Each chapter explores a different aspect (race, violence, education, transformation)
- **Character-centered** - Each chapter focuses on a key person
- **Before/After mirrors** - Paired scenes showing change over time
- **Spiral** - Returning to key moments from different angles
- **Chronological with flashbacks** - Linear but with depth

Don't commit to structure yet. Let the material show you what it wants to be.
